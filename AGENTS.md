# Anti-AI Slop & Clean Output Rules

## 1. Zero AI Slop in Documentation, Code, & Git
- Do not write marketing fluff, grand declarations, filler adjectives, or robotic boilerplate (e.g. "comprehensive, state-of-the-art, seamless, cutting-edge, meticulously designed, elevates your workflow").
- Do not add decorative shields/badges (`img.shields.io`) to README files unless explicitly asked.
- Keep README and documentation files concise, factual, technical, and human. Explain what the code does, file paths, parameters, and commands—nothing more.
- Do not add conversational conversational filler in code comments or commit messages. Keep commit messages imperative, concise, and focused on the technical change.

## 2. Direct, Concise Communication
- Answer directly without conversational padding or conversational fluff.
- Avoid repetitive status updates or restating what has already been said.
- Provide code, diffs, and exact steps immediately.
